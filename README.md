# www.9a3why.space

Source of the website of **9A3WHY** (Amir Jasarevic, amateur radio station, Karlovac, Croatia): https://www.9a3why.space

A static site: plain HTML, CSS and a little JavaScript. No build step, no framework, no cookies, no trackers and no external resources.

## Layout

| Path | What it is |
|---|---|
| `index.html` | Landing page |
| `projects/` | Project pages (pingbot, focusrite, hosting guide) |
| `gallery/` | Photo gallery (`images/`, `images/thumbs/`) |
| `qsl/` | QSL card |
| `privacy/`, `terms/` | Privacy policy and terms of use |
| `404.html`, `robots.txt`, `sitemap.xml` | Error page and crawler files |
| `img/` | Shared images |
